This project implements a REST API using FastAPI to upload, store, retrieve, and process CSV datasets. It reuses data validation and processing modules from MP1 and uses Pydantic models to configure data processing through JSON requests. The API provides endpoints for checking application health, uploading datasets, retrieving stored datasets, and processing datasets through numeric validation, duplicate removal, and missing-value handling. Request logging middleware generates unique request IDs, records HTTP methods, paths, response status codes, and request durations, and handles unexpected errors. The application is tested using pytest and FastAPI TestClient.
